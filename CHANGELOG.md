# Изменения

## 2026-10-01 · Windows-тест и обновление 0.1.1

- В Windows 11/Parallels проверены вход, ошибка SQLite, успешное решение, сохранение прогресса и пауза после Ctrl+C.
- Win+Shift+S исключает защищённое окно Student из захвата Ножницами. Снимок показывает фон/окно позади; обнаружение попытки снимка и штраф за неё не реализованы. Захват VM со стороны Mac остаётся возможным.
- Разделено постоянное browser storage ролей, добавлены сохранение черновика перед закрытием и flush при выходе. В установленной 0.1.1 новый черновик восстановлен после закрытия и повторного входа.
- Заголовок Windows-окна закреплён за ролью. Артефакт CI содержит только два установщика, без дублирующих unpacked executable.

## 2026-10-01 · Проверка desktop-упаковки

- Проверен состав упакованного Student на macOS arm64: нет серверных файлов, каталога и SQLite WASM.
- SQL worker преподавателя собирается с собственным sql.js и распаковывается рядом с WASM, чтобы путь запуска worker был реальным в установленном приложении.
- Сборка исходного сайта и TypeScript проходят; Windows workflow запущен отдельно.

## 2026-10-01 · Отдельный desktop-прототип

- Начата ветка codex/desktop от GitHub main; основная версия сайта не изменена.
- Добавлены преподавательское и ученическое приложения Electron с отдельными правилами упаковки.
- Каталог и эталонные ответы остаются на стороне преподавателя; SQL исполняется в отдельном ограниченном по времени worker с sql.js.
- Индивидуальные логины, scrypt-хеши паролей, локальная SQLite для результатов, назначений и сохранённых проектов.
- Правки заданий проверяются перед сохранением; начатые задания и цепочки проектов фиксируют свою версию.
- Запрет копирования/вставки выбирается для конкретного задания; пауза 30 секунд и снятие паузы преподавателем. Добавлен вызов защиты захвата Electron для Windows, требующий проверки в Parallels.
- Проверены 120 решений и три проекта новым серверным проверяющим кодом; вход, роли, ошибки SQL, бесконечный запрос, перезапуск и сохранение. TypeScript проверен. Ученический экран проверен в браузере.
- Подготовлен GitHub Actions для тестовых установщиков Windows x64. Сеть класса, TLS, тест установщиков на Windows, обновления и миграция существующих ученических данных ещё не завершены.
