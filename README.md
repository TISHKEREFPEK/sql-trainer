# SQL-тренажёр

Русскоязычный интерактивный тренажёр SQL на SQLite: короткие задания, учебные проекты и справочник терминов.

## Локальный запуск

Требуется Node.js 22.13+ и pnpm. Выполните:

```bash
pnpm install
pnpm dev
```

Проект публикуется через OpenAI Sites. Для локальной разработки не добавляйте секреты в Git: `.env*` и `.dev.vars` исключены из репозитория.
