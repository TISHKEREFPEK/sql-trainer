## Свободное преобразование деталей · 23 октября 2026

Выбранная деталь выделяется синей рамкой по её повернутым границам. Четыре угловых маркера меняют ширину и высоту независимо, круглый маркер вращает на любой угол. Курсор размера учитывает направление угла; курсор вращения — рука. Shift сохраняет пропорции при растяжении и задаёт шаг 15° при вращении, Escape отменяет текущий жест. Один жест — один шаг отмены; точки подключения, провода, просмотр работ преподавателем и SVG используют то же преобразование.

JSON v1 расширен необязательными Angle=0, StretchX=1 и StretchY=1; старые Scale, QuarterTurns и зеркальный Rotation сохраняют поведение. Растяжение ограничено 0.1–10 по каждой оси, угол нормализован в [0,360). Сервер и проверка резервных копий принимают и проверяют новые поля без изменения таблиц или миграции. Цвет рамки задаётся в свойствах как #RRGGBB и сохраняется локально рядом со схемой в .selection-color; он не входит в ученическую работу. Обновлять Teacher/Server и Student вместе. Электрические параметры от преобразования не меняются.

## Результаты учеников по электронике · 23 октября 2026

В кабинете преподавателя на стенде «Электроника» добавлена вкладка «Результаты учеников»: фильтр группы и поиск ученика, текущие схемы, код и история компиляций/запусков/отправок. Просмотр снимков только для чтения, без исполнения программы ученика и замены схемы преподавателя. Данные обновляются при открытии вкладки и кнопкой «Обновить». Ученик передаёт текущую схему автоматически (интервал 2 с), фиксирует готовую работу кнопкой «Отправить преподавателю». Ошибки и результаты запусков сохраняются отдельными неизменяемыми снимками; это сообщения приложения, не автоматические оценки.

Добавлены нативные EF-таблицы ElectronicsWorks и ElectronicsReports с миграцией ElectronicsResults; старые миграции не менялись. Сервер сначала создаёт резервную копию и применяет миграцию. Восстановление проверяет новые таблицы, JSON, ссылки и хеши. Это SQLite приложения Avalonia, D1 и схема сайта не меняются. Требуется обновить Teacher с Server/Storage/Contracts и Student вместе.

Локальная очередь <файл-схемы>.sync.json хранит черновик и до 100 неотправленных событий (до 16 млн символов снимков), переносит обрыв связи/перезапуск; подтверждённые события удаляются после ACK, повторная доставка идемпотентна. В очереди нет пароля или токена. Копии с разных устройств не перезаписывают друг друга (до 10 копий на ученика). Более старая версия одной копии отклоняется с объяснением. Даты в отчёте — время получения сервером. История выдаётся страницами по 30 событий, ошибка компилятора ограничена 16000 символами с отметкой о сокращении.

Сначала ученик читает задание, затем объяснение и пример. В карточке есть раскрываемые таблицы с данными, краткие определения и две подсказки. Подробный словарь находится в «Повторении». При ошибке показаны точный ответ SQLite и пояснение на русском. Таймера в интерфейсе ученика нет.

## Варианты заданий

- Первые два вводных упражнения общие. Для остальных 118 предусмотрены четыре версии: основная и три альтернативы.
- При входе по коду группы и псевдониму версия закрепляется в D1. Четыре последовательно зарегистрированных ученика группы получают разные номера для одного задания; пятый повторяет один из четырёх.
- Альтернативы используют отдельные имена таблиц, изменённые числовые данные, а некоторые задачи — другие условия. Это автоматически подготовленные версии одной учебной цели, не четыре независимо написанных упражнения.
- Все шаги одного проекта используют одну версию базы. Выданные задания сохраняются целиком: обновление каталога не меняет работу уже зарегистрированного ученика.
- Гости работают с общей основной версией. Для разных вариантов ученики должны войти в группу.

Варианты затрудняют прямое копирование ответа, но не заменяют контрольную систему: ученик может адаптировать запрос или посмотреть клиентский код. Вход «код + имя» также не подтверждает личность.

## Версия для компьютерного класса

Ветка **codex/desktop** развивается отдельно от сайта на main. В desktop/ находится прототип приложений преподавателя и ученика. Инструкция запуска, сборки Windows и ограничения — в [desktop/README.md](desktop/README.md). Обе роли обновлены до 0.1.1 в Windows 11/Parallels. Исправление сохранения черновика проверено закрытием и повторным запуском Student; данные преподавателя и прогресс сохранены. Win+Shift+S исключает защищённое окно из снимка. Это пока тест на одном компьютере; сеть класса и TLS ещё не реализованы. Отправка этой ветки не обновляет Sites. В исходниках 0.1.2 исправлены списки, раскрывающиеся элементы и сетка рабочих панелей; [аудит desktop-функций](docs/desktop-review.md) описывает недостающие части и подготовку будущего редизайна.

## Быстрый старт

Нужны Node.js ≥22.13 и pnpm 11. Команды выполняются в корне **этого репозитория**, где находится `package.json`.

```sh
pnpm install --frozen-lockfile
pnpm build
```

На новой локальной базе примените миграции по порядку:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_ambitious_kylun.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_teacher_tasks.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0002_task_variants_analytics.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0003_learner_variant_assignments.sql
pnpm dev
```

Для существующей базы применяйте только отсутствующие миграции. Не запускайте старые повторно и не удаляйте базу ради обновления. `db:generate` нужен при изменении схемы, а не при обычном запуске.

Для входа преподавателя создайте локальный `.dev.vars` с `ADMIN_PASSWORD_HASH=<SHA-256 выбранного пароля>`. Файл игнорируется Git. На опубликованном сайте одноимённый секрет задаётся отдельно в Sites. Вход расположен в меню шестерёнки.

## Проверка изменений

```sh
pnpm exec tsc --noEmit
pnpm check:variants
pnpm build
```

Проверка вариантов выполняет 480 эталонных решений, последовательные проекты, перенос гостевой базы и отклонение неизменённых чужих ответов для самостоятельных упражнений. Дополнительно вручную проверяйте затронутые экран, вход, сохранение и мобильную навигацию.

## Совместная работа

Исходники передаются через GitHub; у каждого участника свой локальный проект и чат с помощником. История чата не синхронизируется с кодом. Перед началом работы получите актуальную ветку, затем создайте отдельную ветку для своей задачи и отправляйте изменения через pull request. Не используйте принудительную отправку общей ветки.

На текущем Windows-ПК `origin` указывает на `TISHKEREFPEK/sql-trainer` в GitHub. В прежнем окружении Sites имена remote отличались; на каждом компьютере сначала смотрите `git remote -v`, не полагайтесь на старые названия.

**Отправка кода в GitHub не обновляет размещённый сайт.** Публикация Sites и миграция серверной D1 выполняются отдельно после проверки. Для этой версии перед публикацией необходима миграция `0003` (и ранее отсутствующие миграции).

### Подсказки desktop

В локальной desktop-переработке открытия подсказок сохраняются в профиле ученика и отображаются в статистике преподавателя. Повторный вход восстанавливает открытые тексты. Требуется будущая сборка обновлённых приложений; существующие установщики не изменены.

### Оформление desktop

В локальной переработке есть шесть тем и настройка собственных цветов. Кнопка Оформление доступна после входа; тема сохраняется в профиле ученика или преподавателя. Текущие Windows-установщики требуют будущей пересборки для получения этой возможности.

### Личные пресеты оформления

В локальной desktop-версии можно сохранить до 30 собственных тем с названиями, выбрать их в «Мои темы» и удалить. Пресеты сохраняются сразу, независимо от отмены смены активной темы. Они привязаны к профилю ученика или преподавателя и восстанавливаются при входе. Новые установщики и публикация не выполнялись.

## Desktop 0.1.3 · 7 октября 2026

Подготовлено обновление обеих Windows-ролей: переработанный интерфейс, последовательные подсказки с постоянным учётом в статистике преподавателя, шесть тем оформления и до 30 личных пресетов на профиль. Публикация выполняется отдельно в `codex/desktop`, без объединения с main и обновления Sites. Windows-установщики собирает GitHub Actions; статус сборки и артефакты требуют отдельного подтверждения. Существующая база преподавателя и профили сохраняются. Установка 0.1.3 в Windows ещё не проверена.

Новая пустая схема содержит только пустые setup() и loop(); пример Blink сохраняет собственную программу. Добавление компонента не вставляет код автоматически.
