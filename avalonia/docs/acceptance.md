# Приёмка в Windows и кабинете

Фиксируйте дату, версию, компьютер/ОС и результат каждого пункта. Используйте копии исходных баз и синтетические профили для нагрузки. Не записывайте пароли или токены в отчёт.

- [ ] Установить Teacher и Student на Windows 11 без отдельного .NET SDK/runtime.
- [ ] Повторить установку на используемой в кабинете Windows 10 x64.
- [ ] Создать учеников и группу, изменить пароль/группу, проверить роли.
- [ ] Импортировать копию Electron: сверить количество, вход прежним паролем, завершение, подсказки, темы, проектный снимок и следующий шаг.
- [ ] Повторить импорт; убедиться, что дубликатов нет. Проверить повреждённый источник и сохранение прежней базы.
- [ ] Соединить два физических компьютера по LAN, проверить адрес интерфейса и firewall.
- [ ] Неверный fingerprint отклоняется; после сопряжения ученику недоступны teacher API/чужой профиль/эталоны.
- [ ] Верное и неверное решение, синтаксическая ошибка SQLite, constraint и transaction, все три проекта.
- [ ] Запуск с изменениями проекта без проверки не сохраняет подтверждённое состояние.
- [ ] Разорвать связь при вводе и отправке проверки, восстановить её; повтор не создаёт вторую попытку.
- [ ] Перезапустить сервер и выполнить повторный вход, проверить несохранённый текст в открытом окне.
- [ ] Закрыть Teacher в tray; Student продолжает работу. «Завершить работу» останавливает сервер.
- [ ] Провести нагрузку 35 клиентов на оборудовании кабинета, замерить очередь и ошибки.
- [ ] Бесконечный SQL останавливается через 5 секунд после начала исполнения; следующий запрос работает.
- [ ] Проверить Windows Job Object: 256 МБ native+managed, kill-on-close, один дочерний процесс; restricted token не получает административные привилегии.
- [ ] Копирование/вставка Ctrl+C/V/X, Shift+Insert, Ctrl+Insert, Shift+Delete, drag/drop для выбранной задачи; 30-с пауза, unlock, обычная задача без ограничения.
- [ ] Win+Shift+S и поддерживаемый захват Windows исключают защищённое окно. Внешний захват VM не считается предотвращённым.
- [ ] Длинные условия, открытые объяснения/подсказки, большие результаты, прокрутка, клавиатура, 100/125/150/200% DPI.
- [ ] Шесть тем и пользовательские цвета, сохранить/удалить 30 пресетов, повторный вход.
- [ ] Редактор основных/альтернативных задач, новое задание, изменения только новым назначениям.
- [ ] Отчёты/CSV, время и ошибки, сохранность результатов после перезапуска.
- [ ] Manual/daily backup, восстановление с повторным входом, запрет restore во время проверки.
- [ ] Обновление установщика поверх предыдущей версии сохраняет базу/сертификат/настройки. Удаление программы не удаляет данные.
- [ ] Student installation не содержит Domain/Storage/Server/Worker, catalog, sqlite/pfx и эталонов.
