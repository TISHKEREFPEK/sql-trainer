# Матрица MCU для E01/E11 · 6 ноября 2026

Это уточнение публичной документации и исходников текущей ветки, **не приёмка симуляции** и не заявление о полноте E01. Импорт Cirkit остаётся отложенным по решению владельца; ИИ исключён из объёма. Остальные возможности редактора, компонентов, кода и автономного запуска остаются обязательными.

## Проверенная граница сравнения

[Официальный список](https://www.cirkitdesigner.com/docs/platforms/) содержит четыре моделируемые платформы. Ниже перечислены заявленные функции; соответствие нашей версии надо доказывать отдельными эталонами. Возможности, прямо отсутствующие у Cirkit, не следует выдавать за уже существующую часть его симулятора.

| Платформа и первичный источник | Заявлено в Cirkit | Ограничения самого Cirkit |
|---|---|---|
| [Uno](https://www.cirkitdesigner.com/docs/platforms/arduino-uno) | ATmega328P; цифровые порты и прерывания, Timer0/1/2, PWM, шесть аналоговых входов, последовательный порт, EEPROM, watchdog | SPI/I2C работают в роли ведущего; аналоговый компаратор отсутствует |
| [Mega 2560](https://www.cirkitdesigner.com/docs/platforms/arduino-mega) | ATmega2560; 54 цифровых/16 аналоговых контактов, четыре последовательных порта, Timer0–5, PWM, EEPROM, watchdog | SPI/I2C — ведущий; захват входа таймеров и аналоговый компаратор не поддержаны |
| [Pico](https://www.cirkitdesigner.com/docs/platforms/raspberry-pi-pico) | ARM Cortex-M0+, GPIO, аппаратный UART/USB CDC, PWM/ADC, таймеры, PIO, часы реального времени и watchdog | Один CPU; SPI/I2C — ведущий; DMA ограничена PIO |
| [ESP32-S3](https://www.cirkitdesigner.com/docs/platforms/esp32-s3) | Два Xtensa, GPIO/маршрутизация, три UART, SPI с DMA, два I2C, таймеры/PWM/ADC, WiFi, криптографические ускорители, flash/PSRAM, watchdog | Arduino, ESP-IDF обещан позднее; WiFi без WPA; RMT только передача, USB RX неполный; нет Bluetooth, PCNT и CAN; упрощены некоторые времена/сон |

ESP32-сетевые примеры документации включают HTTP(S), MQTT, WebSocket и UDP. Для автономной сети кабинета нужны реальные локальные конечные точки и достоверная ошибка при отсутствии внешнего сервиса. Успешный ответ интернета нельзя подменять заранее записанной строкой.

## Что подтверждено у нас исходниками

- `FirmwareRunner.Compile` выбирает единственный FQBN `arduino:avr:uno`; `firmware-worker.cjs` создаёт только ATmega328P: flash 32 КиБ, порты B/C/D, Timer0/1/2, ADC и передачу USART0. Наличие моделей периферии в vendor не означает их подключения к рабочей схеме.
- Протокол Step передаёт цифровые/аналоговые входы и возвращает уровни/PWM/пульсы и serial output. Serial input, SPI/I2C-устройства, EEPROM/watchdog и прочие функции нельзя объявлять проверенными по самому наличию AVR8js.
- Mega/Pico/ESP32 не получают собственную компиляцию/CPU через этот runner. Картинки и точки контактов не закрывают этот пробел.
- Зафиксирован AVR8js 0.21.0 (MIT). В локальном vendor есть порты A–L и ветвления для расширенного счётчика команд; это основание исследовать Mega, а не доказательство его готовности. Адреса периферии/векторы/распиновка должны соответствовать конкретному MCU.
- Проверить размер RAM Uno: текущий вызов `new CPU(program)` использует значение по умолчанию vendor (8192), явный профиль памяти платы не передаётся. Это наблюдение по исходнику; пока не подтверждённый пользовательский баг.

## Следующие эталоны и порядок реализации

| Блок | Эталон для признания функции |
|---|---|
| Профиль MCU/прошивка | Правильная архитектура и размер памяти; отказ чужой/повреждённой/слишком большой прошивке; данные за границей flash, переходы/вызовы и стек, сохранение совместимости Uno |
| GPIO и прерывания | Вход/выход/pull-up и внешние сигналы на правильных физических контактах, крайние номера контактов, внешние и pin-change прерывания |
| Таймеры/PWM/ADC | Аппаратные периоды/частоты/duty, Servo/tone, все разрешённые аналоговые каналы и диапазоны; неверное соединение даёт объяснимую ошибку |
| Serial | Независимые каналы и связь TX/RX, serial monitor/input; объём/ресурсы ограничены, переносы строк и переполнение не смешивают сообщения |
| Протоколы/периферия | Реальные транзакции I2C/SPI с компонентом и ошибками адреса/питания; EEPROM/watchdog и необходимые специфические устройства по отдельным программам |
| Pico | Сначала ядро/память/прошивка и GPIO/UART/USB, затем PWM/ADC/PIO/DMA/RTC и ограничения из таблицы |
| ESP32-S3 | Отдельное доказательство доступного автономного CPU/toolchain, затем перечисленная периферия и локальная сеть; картинки/перевод Arduino-кода в фиктивные значения не подходят |
| Несколько плат | Отдельные прошивки/состояния/контакты, согласованное время и межплатные сигналы; остановка/перезапуск не оставляют процессов и не смешивают работы |
| Поставка | Подготовленный комплект без сети на занятии, лицензии/исходники, ресурсы процесса и реальные Win10/16–32 ГБ; домашний Win11 не заменяет этот пункт |

Ближайший эксперимент — явные профили AVR и настоящий отдельный Mega runner с его картой памяти/портов/таймеров/UART. Сначала проверить доступный toolchain и эталон с контактами вне диапазона Uno; не включать `Simulated=true` всему каталогу до подтверждения моделей. Полная компонентная матрица, пользовательские модели и достоверная графика остаются отдельными открытыми частями E01/E11. [Описание пользовательских компонентов Cirkit](https://www.cirkitdesigner.com/docs/custom-simulation-parts/getting-started) подтверждает необходимость изображения, контактов и поведения; перенос изображения сам по себе не переносит модель.
