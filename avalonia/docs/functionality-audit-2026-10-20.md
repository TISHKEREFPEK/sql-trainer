# Проверка функций и баз · 20 октября 2026

Проверка текущей Avalonia со статистикой, локальных баз и прежних сайта/Electron. Данные владельца не использовались для разрушительных сценариев: негативные проверки, миграции, restore и импорт выполнялись в отдельных временных базах. Учебная редактура по-прежнему отложена.

## Обнаружено и исправлено

| Дефект | Исправление и проверка |
|---|---|
| Restore принимал неполную Classroom-схему, неизвестную будущую версию, нарушенные FK, невалидный JSON и повреждённый проектный снимок | До исправления пять регрессий подтверждали отсутствие отказа. Теперь отдельный stage проходит миграции и DatabaseHealth до замены; добавлена также проверка не-SQLite файла. Все шесть отказов сохраняют рабочую базу. |
| Старое восстановление вручную удаляло WAL и заменяло основной файл | Проверенный stage переносится SQLite backup-транзакцией после before-restore. Успешное восстановление прежней миграции проверено без изменения исходного backup. |
| Вход на паузе вызывал 423 из автоматического preview до запуска polling | Опрос запускается раньше, preview пропускается на паузе. Живой HTTPS/UI-тест подтверждает Load и разблокировку без повторного входа. |
| Постоянный отказ оставлял старый SQL как pending; новая проверка могла повторять отвергнутый код | 4xx, кроме 401/429, освобождают pending. Транспортные повторы сохраняют UUID. Живой UI-тест проверяет отказ 423 и последующий успех именно нового SQL. |
| Async-finally кнопки снова включал проверку завершённого проекта | enabledAfter вычисляется по актуальной политике; проверка готового проектного шага остаётся выключенной, подтверждено живым UI-тестом. |
| Три встроенных Globus seed по 1 058 622 символа не проходили лимит 500 000 в авторинге | Catalog.MaxSeedLength=2 000 000. Регрессия до исправления падала; теперь все штатные задания и альтернативы проходят Catalog.Validate. |
| Неполный/null JSON приводил к серверной ошибке вместо понятного отказа | ASP.NET отклоняет missing/non-nullable null с 400; проверены вход, черновик и выполнение. |
| Сортировка дат/длительности шла по форматированным строкам | Используются UTC timestamps и числовые секунды. Для текстовых отношений используется соседний числовой процент вместо ложной строковой сортировки. |
| При перезаписи CSV мог сохраниться хвост прежнего файла | Поток явно обнуляется перед записью. Нативный экспорт создан и прочитан обратно. |

Execute в интерфейсе сериализован; ответ старой задачи не очищает pending нового задания. Никакой ученический SQL не выполнялся в SQLite метаданных или D1.

## Базы

Обнаружены 12 файлов SQLite: 11 Avalonia (рабочая, демо, прежние копии/backup) и 1 Electron. На read-only подключениях: integrity_check=ok, foreign_key_check без ошибок. SHA-256 источников до/после создания снимков совпал. Настоящих проектных снимков в этих локальных файлах нет; это не подменено утверждением об их проверке.

Для каждой из 11 копий Avalonia выполнены запуск миграций и --check-database, включая таблицы и JSON. Копия Electron успешно импортирована в новую базу и проверена той же командой. Итог 12/12. Сырые отчёты с локальными путями, снимки баз, пароли и данные учеников остаются в игнорируемой .codex, в Git не входят.

Учебные базы проверены отдельно: check:variants исполнил 480 эталонных проверок, подтвердил 120 задач, 118 задач с четырьмя вариантами и все проектные цепочки. Нативные CoreTests проверяют тот же каталог и три проекта во всех четырёх вариантах.

## Выполненные проверки

- Avalonia: 18 проверок логики/API и 28 UI, включая живой HTTPS-сервер, восстановление, негативные backup, неизменность назначений, идемпотентность SQL/событий/подсказок/активности, 35 клиентов, timeout SQL, роли и TLS pinning.
- Администрирование: создание/смена пароля/группы/удаление ученика; удаление группы переводит учеников в «Без группы»; удалённая сессия больше не действует. Новое задание доступно в каталоге; удаление сохраняет уже выданное условие. Сохранение/удаление пресета и предел 30 тем проверены.
- Статистика: четыре уровня, SQL первого принятого ответа и попыток, даты, подсказки, нарушения; страницы истории. Нативный CSV группы: 720 строк/6 учеников; у ученика с нулевым прогрессом есть все 120 неначатых заданий.
- Сайт: pnpm check:variants, pnpm exec tsc --noEmit, pnpm build — успешно. Ничего не размещалось в Sites.
- Прежний Electron: сборка и три node:test — успешно: роли/назначения/проверки/restart, 120 решений/проекты, читаемость тем.
- EF Core: has-pending-model-changes — изменений вне миграций нет. Содержательная миграция статистики LearningHistory сохранена отдельным новым файлом; старые миграции не редактировались.

TRX и изображения: avalonia/artifacts/audit-2026-10-20 и avalonia/artifacts/statistics (игнорируются Git).

## Что этим проходом не подтверждается

Windows 10, два физических ПК/LAN, установка и обновление установщика на машине без SDK, поведение при физическом выключении ПК и внешнем захвате экрана остаются приёмкой кабинета. Удалённая D1 и размещённый сайт не были подключены/изменены. Полная постоянная офлайн-очередь и административный аудит всех действий не добавлялись. Предыдущая ручная проверка Win+Shift+S владельцем остаётся основанием для защиты снимков; не заявляется обнаружение всех системных попыток.
