# Изменения приложений и перенос · 24 октября 2026

## Что изменилось

- Ученик подключается кодом преподавателя, затем вводит свой логин и пароль. Преподаватель показывает код после входа кнопкой в углу, внутри основного окна.
- Преподаватель выбирает стенд SQL / Электроника. Новый вход ученика открывает выбранный стенд. Уже открытые окна автоматически не переключаются; после перезапуска сервера выбран SQL.
- В автономной Электронике — каталог из 147 позиций, четыре оригинальных PNG-атласа с 64 иллюстрациями, поиск, категории, избранное и подписанные контакты Pico. Поддерживается реальная локальная компиляция Arduino Uno и симуляция AVR8js; многие другие платы и детали пока используются для рисования.
- Выбранная деталь имеет синюю рамку. Уголки меняют ширину и высоту, круглый маркер поворачивает на любой угол. Курсор меняется при наведении. Shift сохраняет пропорции или задаёт шаг поворота 15°; Escape отменяет жест. Цвет рамки меняется в свойствах в формате #RRGGBB и сохраняется локально. Провода следуют за контактами; доступны отмена/повтор, JSON и SVG.
- Во вкладке кода есть справка по подключённым поддерживаемым деталям и явная генерация начального шаблона с подтверждением замены; пользовательский код автоматически не переписывается.
- Преподаватель видит «Электроника → Результаты учеников»: фильтр группы, поиск, текущие схемы, код и историю отправок, компиляций и запусков. Просмотр только для чтения. «Обновить» загружает последние результаты.
- Ученик передаёт черновик автоматически и фиксирует работу кнопкой «Отправить преподавателю». Очередь сохраняется при обрыве связи/перезапуске, события повторно не дублируются. Снимки истории сохраняют код и схему на момент события. Результат компиляции не является оценкой правильности задания.
- Ошибки и сообщения появляются в углу приложения и исчезают через 2,5 секунды; подробные SQL/компиляторные сообщения доступны в рабочем разделе.
- Оформление и SQL-справочник открываются встроенными страницами с возвратом. Системный выбор файлов и короткие подтверждения остаются диалогами.
- Повторный запуск занятого сервера объясняет причину отказа без прежнего аварийного завершения.

## Сборка и запуск на другом компьютере

1. Скачать ту же ветку проекта:

   ```powershell
   git clone --branch codex/full-functionality-bugfix https://github.com/TISHKEREFPEK/sql-trainer.git
   cd sql-trainer
   ```

2. Установить .NET SDK 10.0.401. Выполнить `./avalonia/scripts/build-windows.ps1 -SkipInstaller`. Скрипт восстанавливает зафиксированные пакеты, собирает решение, готовит Arduino/Node, запускает тесты и создаёт обе поставки. Для первого выполнения нужен интернет. Готовая электроника работает автономно; для передачи работ нужна локальная связь с преподавателем.
3. Запускать `avalonia/artifacts/publish/Teacher/Classroom.Teacher.exe` и `avalonia/artifacts/publish/Student/Classroom.Student.exe`. При переносе готовой сборки копировать целиком соответствующую папку; в Teacher также обязательны `runtime/server` и `runtime/worker`, в обеих — `electronics/assets` и `electronics/runtime`.
4. Для установщиков нужен Inno Setup 6; запустить сборку без `-SkipInstaller`. Старые установщики с тем же номером версии не содержат эти изменения автоматически.
5. Войти преподавателем, выбрать Электронику, открыть «Код подключения». На ученическом ПК ввести код и учётные данные. Для физической LAN настроить HTTPS-порт и UDP 47832 по [README](../README.md). Демонстрационный адрес 127.0.0.1 работает только на одном ПК.
6. Создать схему учеником, отправить её преподавателю. У преподавателя открыть результаты, выбрать ученика и проверить схему, код и историю. После новых действий ученика нажать «Обновить».

Учётные данные и прежние проекты не скачиваются из GitHub. Для их сохранения нужен отдельный приватный перенос по [инструкции](../../docs/continue-on-another-pc.md). Не копировать работающую SQLite-базу без согласованной резервной копии.

## Данные и совместимость

Добавлена новая EF-миграция ElectronicsResults с таблицами ElectronicsWorks и ElectronicsReports; применённые миграции не редактировались. При старте сервер делает резервную копию перед миграцией. Обновить Teacher/Server и Student вместе, предварительно завершив старые процессы. Сохранены назначенные SQL-варианты и снимки; D1 и веб-приложение не менялись.

JSON схем остаётся version=1: прежние файлы читаются с исходным видом; новые поля Scale/QuarterTurns/Angle/StretchX/StretchY необязательны. Проверка импорта, передачи и резервной копии валидирует формат. Детали ограничения очереди, симуляции и поддерживаемых компонентов — в [документации электроники](electronics.md).

## Выполненные проверки и ограничения

23 октября: все 87 тестов (19 серверных + 68 UI/API) прошли; полная Windows Release-сборка выполнена без предупреждений и ошибок. Проверены очередь после перезапуска, роли API, неизменяемая история, backup/restore, реальные события мыши, отмена/повтор, Escape, сохранение цвета, преобразованные контакты/провода и старый SVG. Визуально проверены окна 900 и 1320 px. Существующая локальная демобаза проверена командой `--check-database`. Проверки переноса изображений выполнены при подготовке публикации 24 октября.

Это не полный аналог Cirkit Designer: эмуляция CPU Mega/ESP32/Pico, полный набор физических моделей, электронные задания, их автоматическая раздача и оценивание ещё не реализованы. Приёмка на двух физических ПК, Windows 10 и реальной сети остаётся отдельным шагом. Main и Sites этой отправкой не изменяются; готовые установщики и toolchain не включаются в Git.
