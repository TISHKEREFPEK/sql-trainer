.NET 10 x64 поддерживает Windows 10 Enterprise LTSC 1809. Ученический установщик допускает сборки от 17763 и выбирает LocalAppData без повышения прав. Политику запуска и работу установщика нужно подтвердить на месте. [Поддерживаемые версии Windows для .NET](https://learn.microsoft.com/en-us/dotnet/core/install/windows).

Windows 10 1809 поддерживает режим WDA_MONITOR. В поддерживаемом захвате она скрывает содержимое защищённого окна. Исключение всей области окна из кадра предусмотрено с Windows 10 версии 2004. Для приёмки на 1809 нужно проверить, видны ли запрос, данные и редактор при Win+Shift+S в обычном и отмеченном задании. [Документация SetWindowDisplayAffinity](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity).

Приёмка на месте включает запуск опубликованной Student-сборки под учётной записью ученика, подтверждение фактического DPI, сопряжение по проводному LAN с адресом преподавателя и TCP 47831, SQL, компиляцию и симуляцию схем без интернета. Для проверки сети Ethernet и VirtualBox учитываются как разные интерфейсы. Отчёт подтверждает характеристики ПК, сетевые параметры и права сеанса на момент сбора.
