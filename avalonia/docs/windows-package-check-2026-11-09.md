## Сборка

Из корня репозитория, PowerShell:

```powershell
./avalonia/scripts/build-windows.ps1 -InnoCompilerPath 'C:/tools/Inno Setup 7/ISCC.exe'
```

По умолчанию новые файлы публикуются в `avalonia/artifacts/publish`, установщики — в `avalonia/artifacts/installers`. Если каталог уже непустой, сборка отказывает, сохраняя его содержимое. Выберите новые `-PublishPath` и `-InstallerOutputPath` внутри `avalonia/artifacts/` или `.codex/`. Упаковщик и его выход проверяются до дорогих загрузок/сборки; `build-installers -CheckPrerequisitesOnly` не требует ещё не опубликованных EXE и не создаёт файлов. Скрипты не удаляют прошлую поставку. Выходные каталоги не должны пересекаться с исходными SDK. Относительные входные пути разрешаются относительно текущего каталога вызывающего.

`build-windows.ps1` выполняет locked restore, Release build, подготовку отдельных AVR/Pico SDK, тесты, self-contained win-x64 publish, копирование SDK, проверку отсутствия учительских файлов у ученика, проверку электроники **из каждого опубликованного EXE**, затем компиляцию установщиков. `-SkipTests` пропускает обычные тесты, но не подготовку Pico и не проверку опубликованного комплекта. `-SkipPackageCheck` и `-SkipInstaller` — отдельные явные исключения, которые необходимо указывать в отчёте проверки. Подготовка SDK на сборочном ПК требует загрузки закреплённых зависимостей; подготовленный комплект рассчитан на автономную работу.

Для повторной упаковки уже проверенных папок без повторного копирования многогигабайтных SDK:

```powershell
./avalonia/scripts/build-installers.ps1 -PublishPath './.codex/my-build/publish' -OutputPath './.codex/my-build/installers-v2' -InnoCompilerPath 'C:/tools/Inno Setup 7/ISCC.exe'
```

Нужен **Inno Setup 7 или новее**: в SDK встречаются пути длиннее MAX_PATH. Версия проверяется через `ISCC --version`, поскольку VERSIONINFO подписанного ISCC 7.1.0 содержит `0.0.0.0`. Само создание установщиков не устанавливает и не запускает приложения. Проверку их установки/обновления проводить на отдельной Windows/VM, не поверх рабочих учётных записей этого ПК.

## Состав SDK и пути

`copy-electronics-runtime.ps1` копирует известные CLI/Node/лицензии, `data`, соответствующий sandbox toolchain, маркеры готовности, закреплённые Adafruit SSD1306/GFX/BusIO и Servo для AVR. Не включает download archives, резервные старые SDK, пользовательские скетчи и исходную локальную конфигурацию. Используется robocopy с поддержкой длинных путей, без `/MIR`/`/PURGE`. Непустой выход отвергается. `classroom-sdk-copy.json` меняет состояние `copying` на `ready` только после всех копирований; маркер не заменяет проверку файлов и выполнения.

Полный дистрибутив Teacher содержит также Server/Worker; Student не должен содержать Domain/Storage/Server/Worker, каталог ответов, SQLite-метаданные, сертификаты и EF/BouncyCastle. Проверка дерева использует extended-length Windows paths. Это фильтр поставки, не замена аудита всех секретов.

## Проверка опубликованного приложения

```powershell
& './.codex/my-build/publish/Student/Classroom.Student.exe' --verify-electronics './.codex/my-build/student-check'
```

Аналогично Teacher. Требуется новый или пустой каталог отчёта; непустой не перезаписывается. Этот режим запускается до окна/входа/базы/настроек пользователя. Он сбрасывает внешние overrides SDK и проверяет пути рядом с EXE. Компилирует собственные фиксированные скетчи Uno/Mega (Serial UTF-8/GPIO) и Pico (настоящие Adafruit OLED/Serial UTF-8), затем запускает прошивки обычными изолированными компилятором и симулятором. Компилятор получает короткий собственный cache под OS temp: физически длинный путь ранее ломал GNU linker при разрешении `avr5.xn`. Никакого увеличения разрешений ученического процесса нет.

`package-check.json` содержит результат, SHA256 Desktop DLL/прошивок, serial и ошибку при сбое. Успешный собственный compiler cache удаляется; при ошибке сохраняется с путём для диагностики. Личные проекты, обычный compiler cache и SDK не удаляются. Электроника проверяется через обычный AppContainer без разрешения сети; это не проверка всей LAN-сессии или полностью отключённого сетевого адаптера Windows.
