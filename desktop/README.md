# SQL · Класс — прототип Windows-приложения

Разработка в **codex/desktop**, без объединения с main и публикации Sites. Текущий этап рассчитан на преподавателя и ученика **на одном компьютере**, например внутри одной виртуальной Windows 11 в Parallels. Это ещё не готовая система для экзамена или сети школы.

## Что работает

- Отдельные роли и установщики преподавателя/ученика.
- Первичная настройка пароля преподавателя, создание ученических логинов и паролей.
- 120 общих заданий, четыре устойчивых варианта, три проекта.
- Проверка SQL у преподавателя; оригинальные ошибки SQLite видны ученику.
- Сохранение прогресса и успешных проектных баз в локальную SQLite; черновики отдельно в localStorage окна приложения.
- Преподаватель изменяет условие, объяснение, исходный SQL и эталон. Новые назначения получают правки; начатые задания и цепочки проектов сохраняют старую версию.
- Настройка ограничений для конкретного задания: copy/cut/paste, пауза на 30 секунд, разблокировка преподавателем. Для Windows предусмотрена защита захвата окна Electron; Win+Shift+S проверен в Windows 11/Parallels, Windows 10 ещё требует отдельного теста.
- Изменение ограничений приходит автоматически в течение примерно двух секунд.

## Запуск из исходников

Нужны Node.js 22.13+ и pnpm 11.19.0. Сначала в корне репозитория:

```sh
pnpm install --frozen-lockfile
```

Затем:

```sh
cd desktop
pnpm install --frozen-lockfile
pnpm build
pnpm install:electron
pnpm teacher
```

В другом терминале из desktop:

```sh
pnpm student
```

Оба приложения должны работать в одной ОС. Mac и Windows-виртуальная машина — два разных компьютера с точки зрения loopback. Запуск обоих внутри Parallels проверяет оболочку Windows. Для соединения Mac/Windows требуется будущий сетевой этап.

Преподаватель задаёт пароль (от 10 символов), создаёт логин ученика и пароль (от 8 символов). Затем ученик входит этими данными. Паролей по умолчанию нет. Если порт 47831 занят другим экземпляром тестового сервера, сначала остановите его.

Данные преподавателя: каталог classroom внутри Electron userData. Точный системный путь зависит от Windows/macOS и названия приложения. Не удалять этот каталог при обновлении. Вход по старому коду группы/имени из сайта и автоматический импорт сайтового прогресса пока отсутствуют.

## Проверка без Electron

```sh
pnpm build
pnpm test
pnpm server
```

Открыть http://127.0.0.1:47831/. Кнопка «Сменить роль» присутствует только в браузерном тесте. Роль всё равно проверяет сервер. Браузерная версия не защищает скриншоты. Серверные данные CLI находятся в desktop/.classroom-data; это отдельная тестовая база, не Electron userData.

Тесты проверяют роли, неверные пароли, отказ доступа с чужого Origin, отсутствие эталонов в ученическом API, ошибки/верные/неверные SQL, настройку ограничений, разблокировку, прерывание бесконечного запроса, восстановление после перезапуска, 120 решений и три проектные цепочки.

## Установщики Windows

На Windows после установки зависимостей и сборки:

```sh
pnpm pack:student
pnpm pack:teacher
```

Результат в release/student и release/teacher. Пока x64; отдельные сборки ARM64/32-bit не подготовлены. Установщики не подписаны сертификатом. Публикации в магазине и автоматического обновления приложения нет.

В GitHub Actions предусмотрен workflow **Desktop Windows test builds** для ветки codex/desktop. После успешной сборки установщики доступны в артефакте SQL-Classroom-Windows-x64-test (хранится 14 дней). Статус workflow нужно проверять; наличие файла workflow само по себе не подтверждает успешную сборку .exe.

## Проверка Windows 11 / Parallels · 1 октября 2026

Проверены вход ученика, оригинальная ошибка SQLite для отсутствующего столбца, успешный SELECT, автоматическое включение ограничения в открытом задании, пауза на 30 секунд после Ctrl+C и запись попытки у преподавателя. Исправление вошло в 0.1.1 и проверено в Windows: введённый без запуска черновик восстановился после закрытия и нового входа; старое хранилище автоматически не переносится. Захват окна Parallels со стороны macOS показывает содержимое даже при включённой защите. Win+Shift+S в Windows Snipping Tool проверен: окно Student исключено из захвата, видно окно позади. Попытка снимка не вызывает паузу. Ручное снятие паузы преподавателем проверено до истечения 30 секунд. Проверка PrintScreen, Windows 10 и локальной сети остаётся открытой. Windows-клиенты пока не считаются готовыми к контрольным.

## Интерфейс 0.1.2

Общие элементы обеих ролей выровнены: список с поиском вместо системного select, единые раскрывающиеся блоки и интервалы. На широком экране учебная карточка и редактор/результат прокручиваются отдельно; на узком сохраняется прокрутка страницы. Прокрутка не отключается для длинного содержимого. Это исправление текущего интерфейса, а не завершённый редизайн. Аудит переноса функций сайта и будущих этапов: [docs/desktop-review.md](../docs/desktop-review.md). Установленная 0.1.1 не получает эти изменения автоматически: требуется новый установщик.

### Учёт подсказок

Открытия подсказок сохраняются в профиле у преподавателя и восстанавливаются ученику при входе. В кабинете отображается таблица использования по ученикам/заданиям с количеством и временем открытия. Отчёты обновляются каждые пять секунд, также есть кнопка Обновить. Пока доступно в локальных исходниках/предпросмотре; установка 0.1.2 сама по себе этой правки не содержит.

### Темы

Оформление после входа: Светлая, Туман, Бумага, Тёмная, Оникс, Полночь. Можно изменить фон, панели, акцент и редактор SQL. Предпросмотр применяется сразу; Сохранить записывает предпочтение в профиль, Отменить/Escape восстанавливает прежнюю тему. Предпочтения разных профилей независимы. Старые профили совместимы.

### Личные пресеты оформления

В локальной desktop-версии можно сохранить до 30 собственных тем с названиями, выбрать их в «Мои темы» и удалить. Пресеты сохраняются сразу, независимо от отмены смены активной темы. Они привязаны к профилю ученика или преподавателя и восстанавливаются при входе. Новые установщики и публикация не выполнялись.
