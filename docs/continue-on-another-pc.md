## Что сейчас разрабатываем

Основная текущая работа — **avalonia/**: C#/.NET 10, два отдельных приложения Windows x64 Teacher/Student, HTTPS и pinning, профили/группы, native SQLite worker на компьютере преподавателя. Учебный SQL не исполняется в базе метаданных или D1. Сайт app/lib и старый Electron desktop остаются в репозитории; это разные реализации. Последний проход не менял их исходники.

Содержательный коммит перед этой передачей — f9377509e37992648297a9fd1519dd180bf97e99. В нём статистика и багфиксы. Последующие документы передачи не меняют исполняемый код.

Принятые решения владельца:

- Русский спокойный интерфейс; без лозунгов и таймеров ученику. Сначала задание, затем обучение; точная ошибка SQLite вместе с понятным объяснением.
- Ограничения Ctrl+C/X/V и захвата окна действуют **только в отмеченных преподавателем заданиях**. Флажок требуется сохранить; политика распространяется на варианты и обновляется у уже открытого ученика.
- Над редактором постоянно виден режим; запрещённое действие с буфером сразу объясняется и вызывает серверную паузу на 30 секунд. Преподаватель может разблокировать ученика.
- Win+Shift+S может открыть Ножницы, но защищённое окно исключается из поддерживаемого снимка. Владелец подтвердил именно исчезновение окна из снимка. Не обещать запрет системного инструмента, обнаружение каждого снимка или защиту от фотографии.
- Статистика: группы → ученики → задания → SQL/история; средний прогресс включает нулевые профили. Показывать трудные задания и число участников, первый принятый ответ отдельно от черновика, проверки, открытые подсказки и обнаруженные нарушения. Нарушение не является доказательством списывания.
- «Время, которое на часах» означает календарные даты/время открытия, действий и решения в зоне преподавателя. Активная длительность хранится отдельно как оценка, ученик её не видит. Не подменять даты общей длительностью между открытием и решением.
- Демоданные владелец разрешил создавать самостоятельно, но в отдельной базе. Рабочие профили не заменять. Старые неизвестные даты/SQL не выдумывать.
- По просьбе «запусти» открывать приложения **и выполнять вход**, а не оставлять формы авторизации. Последний запуск: четыре окна — рабочие Teacher/Student и демонстрационные Teacher/Student. Не требуется открывать по окну для всех 20 синтетических учеников.
- Проверку учебного содержания владелец **отложил**. Не переписывать каталог/выданные варианты в рамках запуска, переноса или технического багфикса.

## Сборка на новом Windows-ПК

Нужен .NET SDK **10.0.401** из avalonia/global.json; lock-файлы уже содержат исправленные криптографические build-зависимости 10.0.13. Не отключать NuGet audit или TreatWarningsAsErrors ради восстановления старых пакетов.

Из корня клона:

```powershell
Push-Location avalonia
dotnet restore Classroom.sln --locked-mode
dotnet build Classroom.sln -c Release --no-restore
Pop-Location
```

После каждой команды проверить успешный код завершения; не запускать старые бинарники после неудачной сборки. Для упаковки и тестов: ./avalonia/scripts/build-windows.ps1 (Inno Setup 6 нужен только для установщиков; -SkipInstaller оставляет папки поставки). Node.js/pnpm нужны сайту, Electron и экспорту каталога, а установленным Avalonia-приложениям не нужны.

23 октября повторно подтверждена успешная [Windows CI 20 октября](https://github.com/TISHKEREFPEK/sql-trainer/actions/runs/39457613746): сборка, проверки, обе self-contained поставки и установщики. [Артефакт SQL-Avalonia-Windows-x64](https://github.com/TISHKEREFPEK/sql-trainer/actions/runs/39457613746/artifacts/12281452938) доступен до 3 ноября 2026 по текущему сроку хранения. В именах установщиков всё ещё 0.1.0, поэтому отличать сборки по commit/run, а не только имени файла. Установка этой сборки на втором физическом ПК ещё не подтверждена.

## Рабочие данные и запуск

GitHub содержит исходники и инструкции, **не содержит** баз, сертификата, паролей, локальных ярлыков и .codex. Для тех же аккаунтов нужен отдельный личный перенос. Перед копированием завершить Teacher через «Завершить работу» (крестик может оставить его в tray), закрыть Student и убедиться, что сервер завершён. Не копировать один основной SQLite-файл из работающей WAL-базы и не удалять WAL вручную.

На исходном ПК рабочие данные восстановлены в avalonia/.classroom-data: classroom.sqlite, server.pfx, server-settings.json, connection.json и backups. Перенести папку после штатной остановки в соответствующее место нового checkout либо использовать корректный backup SQLite вместе с отдельно сохранёнными сертификатом и сетевыми настройками. Сохранить оригинал до проверки входа/прогресса. Прежний Electron импортировать только из копии через предусмотренный импорт; не подменять им Avalonia-файл.

Учётные данные на исходном ПК находятся в игнорируемых .codex/local-access.json и .codex/Пароли.txt. Их можно передать лично вне GitHub; не печатать значения в чат, команды, логи или PR. Если на новом ПК их нет, не считать пустую автоматически созданную базу восстановленными аккаунтами. Демо можно воссоздать независимо.

После сборки, из корня репозитория, в PowerShell:

```powershell
$projectRoot = (Get-Location).Path
Remove-Item Env:CLASSROOM_DEMO -ErrorAction SilentlyContinue
Remove-Item Env:CLASSROOM_STUDENT_DATA -ErrorAction SilentlyContinue
$env:CLASSROOM_DATA = Join-Path $projectRoot 'avalonia/.classroom-data'
if (-not (Test-Path -LiteralPath (Join-Path $env:CLASSROOM_DATA 'classroom.sqlite'))) {
    throw 'Сначала восстановите личную базу; новая пустая база не заменяет перенос.'
}
$env:CLASSROOM_DOTNET = (Get-Command dotnet -ErrorAction Stop).Source
$env:CLASSROOM_SERVER = Join-Path $projectRoot 'avalonia/src/Classroom.Server/bin/Release/net10.0/Classroom.Server.dll'
$env:CLASSROOM_WORKER = Join-Path $projectRoot 'avalonia/src/Classroom.Worker/bin/Release/net10.0/Classroom.Worker.dll'
Start-Process -FilePath (Join-Path $projectRoot 'avalonia/src/Classroom.Teacher/bin/Release/net10.0/Classroom.Teacher.exe') -WindowStyle Normal
Start-Process -FilePath (Join-Path $projectRoot 'avalonia/src/Classroom.Student/bin/Release/net10.0/Classroom.Student.exe') -WindowStyle Normal
```

Абсолютный CLASSROOM_DATA обязателен для восстановленной здесь базы; без него открывается другой стандартный каталог %LOCALAPPDATA%/SQL-Classroom/teacher. Переменные задаются в текущем процессе, не глобально. Сначала войти преподавателем, затем подключить ученика по address/fingerprint из connection.json выбранной базы и войти его профилем. Не публиковать пароль. Рабочий локальный адрес этого переноса — https://127.0.0.1:47831; на другом ПК сверить актуальные настройки.

Сопряжение рабочего Student по умолчанию хранится в %LOCALAPPDATA%/SQL-Classroom/student/connection.json. Для нового сертификата нужна новая сверка отпечатка. Для LAN адрес 127.0.0.1 не подходит: использовать IP преподавателя по инструкции avalonia/README.md, не отключать проверку TLS.

## Демо на новом ПК без личной базы

Следующий пример выполняется из корня клона после Release-сборки, в отдельном PowerShell. Он использует новую игнорируемую папку, не зависит от локальных скриптов прежнего компьютера и не перезаписывает существующую демонстрацию.

```powershell
$projectRoot = (Get-Location).Path
$env:CLASSROOM_DATA = Join-Path $projectRoot 'avalonia/.classroom-data/demo-statistics'
if (Test-Path -LiteralPath $env:CLASSROOM_DATA) {
    throw 'Папка уже существует. Для повторного запуска пропустите создание и --seed-demo; не удаляйте данные.'
}
New-Item -ItemType Directory -Path $env:CLASSROOM_DATA | Out-Null
Set-Content -LiteralPath (Join-Path $env:CLASSROOM_DATA 'server-settings.json') -Value '{"address":"127.0.0.1","port":47833}'
$env:CLASSROOM_DOTNET = (Get-Command dotnet -ErrorAction Stop).Source
$env:CLASSROOM_SERVER = Join-Path $projectRoot 'avalonia/src/Classroom.Server/bin/Release/net10.0/Classroom.Server.dll'
$env:CLASSROOM_WORKER = Join-Path $projectRoot 'avalonia/src/Classroom.Worker/bin/Release/net10.0/Classroom.Worker.dll'
dotnet $env:CLASSROOM_SERVER --seed-demo
if ($LASTEXITCODE -ne 0) { throw 'Не удалось создать демонстрационные данные.' }
$env:CLASSROOM_DEMO = '1'
$env:CLASSROOM_STUDENT_DATA = Join-Path $env:CLASSROOM_DATA 'student-settings'
Start-Process -FilePath (Join-Path $projectRoot 'avalonia/src/Classroom.Teacher/bin/Release/net10.0/Classroom.Teacher.exe') -WindowStyle Normal
Start-Process -FilePath (Join-Path $projectRoot 'avalonia/src/Classroom.Student/bin/Release/net10.0/Classroom.Student.exe') -WindowStyle Normal
```

Для повторного запуска задать те же переменные, пропустив проверку новой папки, её создание, запись настроек и --seed-demo. Вход — по приватному demo-access.json этой базы, подключение — по её connection.json. Генератор создаёт случайные пароли; в GitHub их нет. На исходном ПК демо расположено в .codex/statistics-demo-data; переносить его необязательно. 20 синтетических учеников, четыре группы (одна пустая), 828 назначений/741 завершение/2107 событий — исходное состояние генератора; ручные тесты могут изменить эти числа. У demo-01 длинная история первого задания и черновик, отличающийся от принятого ответа.

Окна должны иметь пометку «Демонстрация», Teacher после входа открывает статистику. Изолированный CLASSROOM_STUDENT_DATA не перезаписывает рабочее сопряжение. При возврате к рабочему запуску обязательно очистить CLASSROOM_DEMO и CLASSROOM_STUDENT_DATA и вернуть CLASSROOM_DATA: локальный старый start-classroom.ps1 сам эти две переменные не очищает.
