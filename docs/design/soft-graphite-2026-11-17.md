# «Мягкий графит» · дополнение к E13 от 17 ноября 2026

В исходниках работают ресурсы «Мягкого графита», список «Моего занятия», боковое меню и новая рабочая область SQL. Полная приёмка Д01–Д15 остаётся открытой.

## Рабочая область SQL · 19 ноября

Материалы слева используют вкладки «Условие» и «Объяснение». Источники данных свёрнуты при открытии задания. Подсказки выдаёт сервер по порядку. Редактор, область результата и материалы прокручиваются независимо. В редакторе доступны отдельные Undo и Redo, сброс возвращает SQL из стартового шаблона.

Панель результата показывает фактические строки, даже если выборка пуста. Ошибки сохраняют исходную формулировку SQLite и пояснение. При неверном ответе SQLite worker различает столбцы, количество строк, порядок и значения. После правки SQL таблица сохраняется с пометкой о предыдущем запуске. Повтор незавершённого запроса использует сохранённый SQL, действие и идентификатор.

Строка сохранения показывает состояние локальной копии и передачи. Из неё открываются подробности, повтор или выбор при конфликте. Справочник использует настоящее содержимое каталога, закрывается кнопкой и по Escape, возвращает фокус. Редактор остаётся в дереве окна и сохраняет текст, выбор и историю отмены.

Release-сборка решения прошла без предупреждений. В финальном интерфейсном прогоне прошли 14 проверок, включая размеры 704×396, 1008×567, 1366×768 и 1920×1080, Undo/Redo, подсказки, повтор прежнего SQL, различия Run и Check, конфликт черновиков и справочник. Отдельный прогон ядра и сервера прошёл 42 проверки. Просмотрены headless-снимки короткого окна, ошибки, зачёта после изменения SQL и справочника. Проверка DPI и Win+Shift+S в установленной Windows-сборке остаётся открытой.

Основные оставшиеся шаги включают общий прогресс на домашнем экране, прежний зачёт схемы при ожидающей пересдаче, оформление преподавателя и проверку установленной версии на Windows с разным DPI.
