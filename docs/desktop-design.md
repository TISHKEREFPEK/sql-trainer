# Desktop: оформление рабочей области

Локальная переработка 7 октября 2026. Исходники: `desktop/ui`. Установщики и Sites не обновлены. Перед публикацией помнить: push в codex/desktop запускает Windows CI со сборкой установщиков.

## Направление

SQL-мастерская: условие и данные рядом с запросом, спокойные инструменты без мотивационных подписей. Главный визуальный акцент — тёмная панель редактора. Цвет не обозначает новые возможности приложения.

| Назначение | Цвет |
|---|---|
| Фон | #EDF2F4 |
| Поверхность | #FFFFFF |
| Текст | #20343D |
| Границы | #D5E0E4 |
| Акцент | #137C80 |

Текст: Segoe UI в Windows, системный шрифт на других платформах. SQL: Cascadia Code / Consolas / Menlo. Внешние шрифты и интернет не требуются. Основной текст 14 px, условие 16 px, заголовок задания 24 px. Не добавлять капслок-подписи, градиенты и декоративные призывы.

## Сетка

- Верхняя панель 72 px; внешние поля и интервалы широкого рабочего окна 12 px.
- Ученик: навигация 232 px, карточка задания, редактор и результат. Условие первое, затем подсказки, объяснение, пример, термины и таблицы. Подсказки открываются последовательно, определения терминов — в одном общем поле. Число выполненных заданий расположено в навигации.
- Преподаватель: список учеников 232 px; форма задания и журнал рядом. Длинная форма прокручивается внутри панели.
- От 1150 px панели занимают высоту окна, содержимое прокручивается внутри. Ниже редактор/результат и преподавательский журнал складываются вертикально. До 700 px навигация располагается над содержимым.
- Фокус клавиатуры видимый. Раскрытия имеют одинаковые шевроны. Выбор раздела/задания остаётся поисковым. Анимация отключается при prefers-reduced-motion.

## Проверки и границы

Проверены браузерный предпросмотр общего desktop UI, вход обеих ролей, оригинальная ошибка SQLite, верное решение и прогресс, раскрытие учебной таблицы, поиск и выбор задания преподавателя. На ширине 680 px обе роли не создают горизонтальную прокрутку. Серверные тесты проходят: роли, назначения, проверка SQL, обновления, ограничения, перезапуск, 120 эталонных решений и три проектных цепочки.

Переработка не добавляет групп, конструктор контрольных или сетевое сопряжение. Функциональный аудит остаётся в desktop-review.md. Windows-приложение с этим дизайном пока не собрано и не проверено: владелец попросил отложить новый установщик.

## Повторный аудит взаимодействий

- Подсказки: одна кнопка открывает очередной исходный элемент task.hints. Количество не зашито в UI. Открытые элементы сохраняются на сервере для каждого профиля и task.id; при входе UI восстанавливает серверный счётчик; тексты и порядок не переписаны. Финальное состояние не предлагает несуществующую следующую подсказку.
- Термины: кнопки с aria-expanded, одно общее поле определения. Повторное нажатие закрывает его; длинный текст не растягивает соседние колонки.
- Навигация: Курс / Практика / Проекты и видимые темы вместо скрытого списка. Учительский список из 120 заданий сохраняет поиск. Название уже открытого варианта обновляется в списке ученика.
- Справочник: обычная кнопка с активным состоянием и возвратом к текущему заданию, черновик сохранён.
- Движение: раскрытия меняют высоту за 200 ms, новые подсказки/определения/результаты появляются за 190 ms, поиск и сообщения — за 180 ms. Уменьшение движения выключает CSS и JS-анимации. Нет постоянных анимаций без действия ученика.
- Поздние ответы загрузки задания, таблиц, справочника и выполнения SQL не меняют уже другую открытую карточку.

Проверка данных: 120 основных задач + 354 альтернативы = 474 версии (два вводных задания общие). Все имеют корректные массивы подсказок. Это проверка структуры данных, а не новая редакторская оценка качества всех текстов. В UI проверены поочерёдное раскрытие, окончание подсказок, независимость разных задач, возврат, Enter, практика с BMW/cars_v2, проект с readers_v4, SQL-ошибка/успех и поиск учителя. На 1440×900 и 680×900 горизонтальной прокрутки нет в обеих ролях.

Номера в списке ученика обозначают порядок внутри выбранной темы; на следующей странице продолжаются с 09. Идентификаторы заданий, назначенные варианты и сохранённый прогресс не меняются.

## Постоянные открытия подсказок

Подсказка отображается после подтверждения сохранения сервером. Ошибка связи оставляет кнопку доступной для повтора и показывает сообщение; UI не заявляет успешное сохранение. Отчёт преподавателя перечисляет только задания с открытиями, включая номера и серверное время. Повторное открытие не создаёт дубль. Проверены UI после перезагрузки/входа и teacher report; серверные тесты проверяют порядок, ошибочные индексы, роли, изоляцию профилей, повторы и восстановление после перезапуска.

Автообновление дополнительно проверено двумя одновременными UI-сессиями: вторая подсказка ученика появилась у преподавателя без ручного обновления, несохранённый текст формы при этом остался на месте.

## Темы оформления

Заготовки: Светлая (исходная SQL-мастерская), Туман (холодная сине-серая), Бумага (тёплая нейтральная), Тёмная (мягкий графит), Оникс (почти чёрный нейтральный), Полночь (синий). Шрифты, размеры и сетка общие. Диалог показывает шесть образцов и четыре основных цвета; меняется весь интерфейс, включая таблицы, формы, раскрытия и статистику. Сохранение привязано к текущему профилю, отмена возвращает сохранённое оформление.

Проверены UI: Оникс после повторного входа, собственный акцент после повторного входа, отмена другой темы. Серверные тесты подтверждают изоляцию двух учеников и преподавателя, сохранение после перезапуска, отклонение неизвестных тем/цветов. Отдельный тест проверяет контраст текста, вторичного текста, кнопок, SQL и ошибок не ниже 4.5:1 для всех шести тем и четырёх крайних собственных палитр. Установщики не создавались.

### Личные пресеты оформления

В локальной desktop-версии можно сохранить до 30 собственных тем с названиями, выбрать их в «Мои темы» и удалить. Пресеты сохраняются сразу, независимо от отмены смены активной темы. Они привязаны к профилю ученика или преподавателя и восстанавливаются при входе. Новые установщики и публикация не выполнялись.
