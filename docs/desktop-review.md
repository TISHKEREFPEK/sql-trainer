# Desktop: аудит и подготовка переработки

Аудит обновлён 7 октября 2026; визуальные исправления локальные, установщики не обновлены. Ветка codex/desktop; main и Sites независимы. Данные установленного приложения не удалять при обновлении.

## Исправления 5 октября

- Вместо стандартного списка Windows — единый список с поиском. Стрелки, Enter/Space и Escape доступны с клавиатуры, выбор сохраняет обработчики исходного select.
- Стрелки раскрытия оформлены одинаково у подсказок, примеров, терминов и таблиц. Фокус клавиатуры сохраняется.
- Общая сетка: 12 px между ученическими панелями, 18 px внутри учебной карточки, 10–12 px между учебными блоками. Базовый размер текста 14 px, условие 16 px.
- Сверху/снизу кнопки выхода оставлен отступ. На широком экране исчезает внешняя прокрутка: длинное содержимое прокручивается в нужной панели. На маленьком экране прокрутка страницы нужна для доступа к редактору.
- Пагинация из одной страницы скрывается. Смена раздела открывает соответствующее задание. Сохранение преподавателем сохраняет выбор задания.
- Ошибка SQL очищает старую успешную таблицу, оригинальная ошибка остаётся видимой.

## Что есть и что отсутствует

| Возможность | Desktop сейчас | Что осталось |
| --- | --- | --- |
| 120 заданий, устойчивые варианты, три проекта | Общий каталог и серверная проверка | Разделение добавлено 7 октября; контрольные пока не отдельная сущность |
| Обучение по карточке | Условие, объяснение, пример, подсказки, термины, таблицы | Полная редакторская проверка всех объяснений и примеров на отсутствие готового ответа |
| Словарь | Подробные определения | Очередь повторения сложных заданий отсутствует |
| SQL и ошибки | Worker, оригинальные ошибки, результаты | Более точные русские объяснения ошибок, полноценное состояние рабочей базы между произвольными запусками |
| Сохранение | Прогресс и успешные проектные снимки у преподавателя, черновик на компьютере ученика | Черновики между компьютерами, резервные копии и восстановление |
| Учётные записи | Преподаватель и ученики с паролями | Группы/классы, восстановление пароля, импорт профилей сайта |
| Изменение заданий | Условие, объяснение, seed и эталон; новые назначения | Редактор подсказок/примеров/вариантов, создание новых заданий, явное обновление начатых назначений |
| Автоматическая доставка | Ограничения доставляются опросом; начатые задания остаются неизменными | Применение новых исходных баз к уже выданным заданиям с предупреждением и резервной копией |
| Отчёты | Число выполненных, последние 20 проверок, копирование, разблокировка | Автообновление преподавательского отчёта, подробный прогресс по темам, группировка типичных ошибок, экспорт |
| Контрольные | Ограничение для отдельного задания, 30 секунд за clipboard, защита окна Windows | Отдельная сущность контрольной, выдача наборов/период доступа; обнаружение скриншота отсутствует |
| Windows | Отдельные установщики, 0.1.1 проверена на Windows 11 | Проверка 0.1.2 и Windows 10, подпись и автоматическое обновление |
| Компьютерный класс | Только два приложения в одной ОС, loopback | TLS, сопряжение, сеть школы, нагрузка ~20 учеников |
| Шифрование | Хеши паролей, серверные роли | Шифрование хранилища/резервных копий; код приложения не становится неизвлекаемым |

Отключение clipboard применяется только к выбранным заданиям. Защита Windows не предотвращает фотографию или захват VM со стороны Mac. Запрет скриншотов нельзя описывать как абсолютную защиту от списывания.

## Основа для будущего плана визуальной переработки

1. Согласовать карту экранов: ученик (курс / практика / проекты / контрольные / справочник), преподаватель (классы / задания / контрольные / результаты / настройки).
2. Выбрать типографику, шкалу интервалов, плотность, цвета и состояния компонентов. Подготовить один ученический и один преподавательский экран для согласования.
3. Продумать расположение таблиц базы и результатов рядом с редактором, сохранение рабочего пространства, доступность на малом окне и при увеличении масштаба.
4. После согласования перенести систему компонентов на остальные экраны. Проверить клавиатуру, длинные условия, SQL-ошибки, большие таблицы и реальный Windows 10.

Это перечень решений для следующего этапа, а не утверждённый полный план редизайна. Сначала нужно выбрать визуальное направление и состав необходимых функций.

## Проверки этой правки

Локальный просмотр использует тот же desktop/ui, который упаковывается в оба Windows-приложения; отдельная временная база, без данных установленного преподавателя. Проверены ученические SQL/ошибка, выбор раздела, клавиатура списка, раскрытие базы, поиск задания преподавателем и сохранение выбранного задания. На 1440×900 преподавательский документ имеет высоту 900 px; длинная форма прокручивается внутри рабочей панели. Desktop-сборка, два серверных теста (включая все 120 решений и три проекта) и сборка сайта проходят. Эти проверки не подтверждают поведение установленной Windows-сборки 0.1.2.

## Повторный аудит 7 октября

Проверены подсказки, определения, темы/категории, справочник, редактор и ошибки, таблицы, преподавательский поиск и формы. Удалены вложенные раскрытия подсказок и независимые колонки терминов. Возвращена анимация действий. Проверены задания курса, практики и проекта, включая назначенные варианты. Справочник возвращает ученика к заданию; открытые подсказки разных задач независимы. Поздние ответы больше не переписывают другую карточку. Подробности проверки: desktop-design.md.

Функциональные пробелы из таблицы выше сохраняются: этот проход исправляет UI, не реализует локальную сеть, резервные копии, редактор подсказок, группы или сущность контрольной. Предпросмотр не подтверждает поведение установленной Windows-версии.
