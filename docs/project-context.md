## Свободное преобразование деталей · 23 октября 2026

Выбранная деталь выделяется синей рамкой по её повернутым границам. Четыре угловых маркера меняют ширину и высоту независимо, круглый маркер вращает на любой угол. Курсор размера учитывает направление угла; курсор вращения — рука. Shift сохраняет пропорции при растяжении и задаёт шаг 15° при вращении, Escape отменяет текущий жест. Один жест — один шаг отмены; точки подключения, провода, просмотр работ преподавателем и SVG используют то же преобразование.

JSON v1 расширен необязательными Angle=0, StretchX=1 и StretchY=1; старые Scale, QuarterTurns и зеркальный Rotation сохраняют поведение. Растяжение ограничено 0.1–10 по каждой оси, угол нормализован в [0,360). Сервер и проверка резервных копий принимают и проверяют новые поля без изменения таблиц или миграции. Цвет рамки задаётся в свойствах как #RRGGBB и сохраняется локально рядом со схемой в .selection-color; он не входит в ученическую работу. Обновлять Teacher/Server и Student вместе. Электрические параметры от преобразования не меняются.

Проверено: 19 серверных и 68 UI/API-тестов прошли. Новые проверки используют реальные события мыши для поворота на 37°, независимого растяжения, отмены/повтора и Escape; проверяют сохранение цвета, прикрепление проводов и серверную передачу преобразованных схем. Скриншоты 900 и 1320 px проверены визуально. Прежние SVG, зеркальные и четверть-оборотные преобразования сохранены.

## Результаты учеников по электронике · 23 октября 2026

В кабинете преподавателя на стенде «Электроника» добавлена вкладка «Результаты учеников»: фильтр группы и поиск ученика, текущие схемы, код и история компиляций/запусков/отправок. Просмотр снимков только для чтения, без исполнения программы ученика и замены схемы преподавателя. Данные обновляются при открытии вкладки и кнопкой «Обновить». Ученик передаёт текущую схему автоматически (интервал 2 с), фиксирует готовую работу кнопкой «Отправить преподавателю». Ошибки и результаты запусков сохраняются отдельными неизменяемыми снимками; это сообщения приложения, не автоматические оценки.

Добавлены нативные EF-таблицы ElectronicsWorks и ElectronicsReports с миграцией ElectronicsResults; старые миграции не менялись. Сервер сначала создаёт резервную копию и применяет миграцию. Восстановление проверяет новые таблицы, JSON, ссылки и хеши. Это SQLite приложения Avalonia, D1 и схема сайта не меняются. Требуется обновить Teacher с Server/Storage/Contracts и Student вместе.

Локальная очередь <файл-схемы>.sync.json хранит черновик и до 100 неотправленных событий (до 16 млн символов снимков), переносит обрыв связи/перезапуск; подтверждённые события удаляются после ACK, повторная доставка идемпотентна. В очереди нет пароля или токена. Копии с разных устройств не перезаписывают друг друга (до 10 копий на ученика). Более старая версия одной копии отклоняется с объяснением. Даты в отчёте — время получения сервером. История выдаётся страницами по 30 событий, ошибка компилятора ограничена 16000 символами с отметкой о сокращении.


Проверка результатов электроники: прошли 19 серверных и 62 UI/API-теста, включая очередь после перезапуска, изменения во время передачи, разграничение доступа, неизменяемые снимки и восстановление резервной копии с работами. Просмотр схемы проверен при ширине 1320 px, кода — 900 px. Сборка Release выполнена без предупреждений и ошибок. Выдача заданий по электронике и автоматическая оценка остаются отдельными задачами.

## Стенд ученика и контакты Pico · 23 октября 2026

Схема преподавателя не раздаётся: у каждого ученика отдельный локальный JSON по отпечатку сервера и ID профиля. Portable-компилятор теперь включается и в Student. Схема БД не меняется.

Для неизвестных моделей доступны явно логические P1…Pn, их можно переименовать; это не заводская распиновка. Pico пока поддерживает соединение проводов, эмуляция его CPU ещё не реализована.

Владелец попросил реализовать обзор групп, средний процент завершения, трудные задания, переход к ученикам и конкретной работе с SQL-ответами, датами, подсказками и нарушениями; синтетические данные для просмотра создать самостоятельно.

Полный административный аудит, постоянная офлайн-очередь при аварийном закрытии, учебная редактура и физическая сеть остаются отдельными задачами. Время старых назначений может быть неточным; новые поля истории оставляются пустыми, если раньше не записывались.

## Задача

Учить SQL с нуля на русском, небольшими понятными шагами. Ученик учится по карточке задания, имеет возможность ошибаться, читать оригинальное сообщение SQLite и смотреть таблицы рядом с редактором. Подробный словарь доступен для добровольного углубления.

## Решения владельца

- Первый диалект SQLite; 120 упражнений, три последовательных проекта.
- Гостевой режим без регистрации; групповой профиль по коду и псевдониму. Один преподаватель с отдельным паролем.
- Не показывать ученику время выполнения. Статистика активного времени для преподавателя уже реализована отдельно.
- Общие два вводных задания; четыре версии остальных, устойчивое назначение профилю.
- Спокойная типографика, ровные карточки, минимум лишних подписей. Никаких «Твой маршрут» и «Можно ошибаться».
- Компактные разделы вместо постоянного списка всех 120 заданий. Преподавательский вход в настройках.
- Документация должна идти вместе с изменениями, чтобы помощники другого участника быстро понимали устройство проекта.
