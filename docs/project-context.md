# Контекст проекта

## Задача

Учить SQL с нуля на русском, небольшими понятными шагами. Ученик учится по карточке задания, имеет возможность ошибаться, читать оригинальное сообщение SQLite и смотреть таблицы рядом с редактором. Подробный словарь доступен для добровольного углубления.

## Решения владельца

- Первый диалект SQLite; 120 упражнений, три последовательных проекта.
- Гостевой режим без регистрации; групповой профиль по коду и псевдониму. Один преподаватель с отдельным паролем.
- Не показывать ученику время выполнения. Статистика активного времени для преподавателя уже реализована отдельно.
- Общие два вводных задания; четыре версии остальных, устойчивое назначение профилю.
- Спокойная типографика, ровные карточки, минимум лишних подписей. Никаких «Твой маршрут» и «Можно ошибаться».
- Компактные разделы вместо постоянного списка всех 120 заданий. Преподавательский вход в настройках.
- Документация должна идти вместе с изменениями, чтобы помощники другого участника быстро понимали устройство проекта.

## Границы

Четыре версии повторяются при больших группах. Автоматические варианты меняют пространство имён таблиц и часть данных/условий; это не полноценные индивидуальные экзамены. Гости видят основную версию. Вход по известным коду и имени позволяет открыть чужой профиль; не просить личные данные.

Новые назначения фиксируют каталог целиком. Преподавательские правки действуют на новые назначения; административного массового переназначения существующим ученикам сейчас нет. Исторические проектные снимки сохраняют прежний алгоритм вариантов, чтобы не сломать продолжение.

## Desktop-направление · 1 октября 2026

Владелец разрешил публикацию отдельной ветки codex/desktop, без PR и объединения с main; Sites не обновлять этим направлением. Цель — Windows-приложения преподавателя и примерно 20 учеников в классе. Windows 10 в школе; первый тест Windows 11 через Parallels на Mac владельца. Устройство школьной сети пока неизвестно.

Ограничения copy/paste только на выбранных преподавателем контрольных, не во всём курсе и не обязательно во всех контрольных. Не обещать полное предотвращение списывания или обнаружение каждого скриншота.

Первый этап — loopback-прототип двух ролей, серверная проверка общего курса и локальное сохранение. Следующие этапы: получить и испытать Windows установщики, затем HTTPS/сопряжение компьютеров, настройка локальной сети, резервные копии/восстановление, миграция данных при необходимости, управление версиями назначений и нагрузка 20 учеников. Не описывать прототип как готовую экзаменационную систему.

### Результат первого Windows-теста · 1 октября 2026

Оба установщика 0.1.0 запускаются в Parallels. Проверены SQL-ошибка, верное решение, прогресс после перезапуска Student, доставка restrictions, пауза Ctrl+C и журнал преподавателя. Черновик не восстановился: в исходниках разделены persistent browser sessions и добавлен flush при выходе; новая упаковка и повторная проверка пока требуются. Захват VM со стороны Mac обходит защиту Windows-окна; Win+Shift+S в Windows Snipping Tool проверен: окно Student исключено из снимка, вместо него виден фон/окно позади. Ручная разблокировка и перезапуск Teacher в UI пока не проверены. Пароли тестового входа в документацию не записывать.
